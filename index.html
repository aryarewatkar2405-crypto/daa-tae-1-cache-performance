Theoretical Foundations

Big-O Complexity vs. Memory Architecture

Why theoretical operation counts do not always predict real wall-clock latency.

01

Algorithmic Complexity

Asymptotic notation (such as O(n) or O(log n)) classifies how operation count scales as input size N tends toward infinity. However, standard models assume uniform memory access cost (1 unit of time per read/write), ignoring the multi-tier latency of modern CPU caches.

02

Cache Locality

CPUs fetch entire 64-byte cache lines. Contiguous array structures maximize spatial locality because inspecting one record preloads neighboring elements. Conversely, node-based pointer structures (like BSTs) scatter objects in the heap, causing pointer chasing and cache evictions.

03

Experimental Measurement

By precisely tracking wall-clock time with performance.now() while scaling payload sizes and record counts, this lab models working sets that cross from L1 residence into L2 and Main Memory pressure regions.
